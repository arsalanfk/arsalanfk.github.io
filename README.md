# arsalanfakhraei.ca

Static portfolio site. No build step: every file in this folder is served as-is by GitHub Pages.

- `index.html` — home (bio, selected work)
- `work/` — project pages and the interactive dashboard
- `assets/pdf/` — resume, IFC pitch deck, market briefings, sample daily report
- `assets/img/` — thumbnails; add `headshot.jpg` (square, ≥600px) here to replace the photo placeholder
- `CNAME` — tells GitHub Pages the custom domain

To update the resume: replace `assets/pdf/Arsalan_Fakhraei_Resume.pdf` with the new file, same name.
